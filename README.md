# Ralf Smithers Workflows

Public workflow pack for Smithers.

## Directory Manifest

This repo is publishable through [smithers.directory](https://www.smithers.directory/) with the root `smithers-directory.json` manifest. The manifest should list only authored workflows, not the default workflows generated by `smithers-orchestrator init`.

After pushing to GitHub, install the full pack with:

```bash
npx smithers-directory add owner/repo
```

Install one workflow with:

```bash
npx smithers-directory add owner/repo@implement
```

## Layout

- `.smithers/workflows/` contains runnable Smithers workflows.
- `.smithers/prompts/` contains shared MDX prompt templates.
- `.smithers/components/` contains reusable workflow components.
- `.smithers/agents.ts` maps workflow agent slots to Codex.

## Setup

Install dependencies inside the Smithers workflow project:

```bash
cd .smithers
bun install
```

From the repo root, list available workflows:

```bash
bunx smithers-orchestrator workflow list
```

From the repo root, run a workflow:

```bash
bunx smithers-orchestrator workflow run implement --prompt "Describe the change"
```

Smithers stores generated runtime state under `.smithers/` in ignored paths such as `executions/`, `runs/`, `sandboxes/`, `state/`, and local SQLite databases.
